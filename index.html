What I focus on

Four areas I keep coming back to when I design software.

Architectures

Choosing structure before writing code: clear boundaries between frontend plugins and backend services, and decisions the team can explain.

Microservices

Designing RESTful APIs and microservices in C# and .NET that communicate cleanly and ship through Azure DevOps CI/CD pipelines.

Plugin architecture

Building Angular interfaces for a plugin-based frontend, so features plug into a stable core instead of changing it.

Low-code / no-code

Configurable building blocks and form or workflow builders that let non-developers create what they need.

Engineering in the AI era

AI writes code quickly. Teams still need someone who decides what to build, how it fits together and whether it is safe to ship.

Design stays with me

I set service boundaries, API contracts and data models first, before any tool writes a line of code.

AI as an accelerator

I use Claude and Claude Code for scaffolding, refactors, tests and exploring options, then verify what they produce.

Quality gates stay human

Pull request reviews, CI/CD pipelines and demos to product and leadership keep speed from costing reliability.
